# Dycers

**Dycers** is a mobile application for iOS and Android that helps users spot mathematically favourable betting opportunities — arbitrage and freebet optimisation — across licensed bookmakers.

It is an **information and analytics tool only**: it does not place bets, does not accept stakes, and is not a bookmaker or a betting operator.
