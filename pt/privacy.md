# Política de privacidade — Dycers

**Última atualização:** 28 de maio de 2026
**Data de entrada em vigor:** 28 de maio de 2026

A presente Política de privacidade explica como a aplicação móvel «**Dycers**» (a «**Aplicação**») recolhe, utiliza, partilha e protege os seus dados pessoais, em conformidade com o Regulamento Geral de Proteção de Dados da UE («**RGPD**») e as normas locais equivalentes.

## 2. Dados pessoais que recolhemos

### 2.1 Dados que nos fornece

| Dado | Quando o recolhemos | Finalidade |
|------|---------------------|-----------|
| **Endereço de e-mail** | Registo, início de sessão, alteração de e-mail, reposição de palavra-passe | Identificação de conta, autenticação, e-mails transacionais |
| **Palavra-passe (hash)** | Registo, alteração de palavra-passe | Autenticação. Nunca armazenamos palavras-passe em texto claro — são submetidas a hash com bcrypt. |
| **Códigos de verificação** | Registo, reposição de palavra-passe, alteração de e-mail | Verificar a sua identidade |
| **Casas de apostas selecionadas** | Integração e definições | Filtrar alertas de arbitragem |
| **Desportos / ligas selecionados** | Integração e definições | Filtrar alertas |
| **Apostas registadas** | Ao adicionar uma aposta | Acompanhamento, histórico e estatísticas |
| **Nível de subscrição** | Após compra ou restauro | Desbloquear as funcionalidades correspondentes |

### 2.2 Dados recebidos de terceiros

| Dado | Fonte | Finalidade |
|------|-------|-----------|
| **Identificador Apple + e-mail + nome** | Iniciar sessão com a Apple | Criação de conta / início de sessão |
| **ID de conta Google + e-mail + nome** | Iniciar sessão com o Google | Criação de conta / início de sessão |
| **Recibo de compra + estado de subscrição** | App Store, Google Play, RevenueCat | Verificar subscrição |
| **Identificador publicitário móvel (IDFA / GAID)** | O seu dispositivo, apenas com permissão | Mostrar anúncios (apenas nível gratuito) |
| **Token de notificação push** | O seu dispositivo, com permissão | Enviar alertas de arbitragem |

### 2.3 Dados recolhidos automaticamente

| Dado | Finalidade |
|------|-----------|
| **Idioma / definições regionais aproximadas** | Apresentar a Aplicação no seu idioma |
| **Versão da Aplicação, tipo e versão do SO** | Diagnóstico técnico |
| **Registos de acesso ao servidor** (IP, timestamp, endpoint, estado HTTP) | Segurança, prevenção de abusos. Conservados 30 dias. |
| **Registos de falhas e erros** (sem conteúdo pessoal) | Monitorização da estabilidade |

## 4. Com quem partilhamos os seus dados

Nunca vendemos os seus dados pessoais. Partilhamo-los apenas com os seguintes prestadores de serviços:

| Prestador | Função | Dados partilhados | Localização |
|-----------|--------|-------------------|------------|
| **Railway** | Alojamento do servidor backend | Todos os dados de conta, apostas, definições | EUA (Cláusulas Contratuais-Tipo) |
| **PostgreSQL gerido** (via Railway) | Base de dados | Idem | EUA |
| **Brevo** | E-mail transacional | Endereço de e-mail e códigos de uso único | França / UE |
| **Apple** | Iniciar sessão com a Apple, App Store, IAP, APNs | ID Apple, recibos, tokens push | EUA |
| **Google** | Iniciar sessão com o Google, Google Play, FCM, AdMob | ID Google, recibos, tokens push, ID publicitário | EUA / Irlanda |
| **RevenueCat** | Gestão de subscrições | ID de utilizador anónimo, recibos | EUA |
| **The Odds API** | Dados de quotas | Nenhum — apenas saída | Reino Unido |
| **Fornecedor de estatísticas de futebol** | Estatísticas e H2H | Nenhum — apenas saída | UE / Reino Unido |
| **Google AdMob** | Publicidade nível gratuito | ID publicitário móvel (se consentido) | EUA / UE |
| **Expo** | Infraestrutura de notificações push | Token push, carga de notificação | EUA |

No **nível gratuito**, a Aplicação pode exibir publicidade através do **Google AdMob**. Pode alterar as suas preferências em qualquer momento nas definições do dispositivo. Os utilizadores pagos (Pro / Max) não veem publicidade.

## 7. Períodos de conservação dos dados

| Dado | Período de conservação |
|------|----------------------|
| Dados de conta | Enquanto a sua conta estiver ativa. Eliminados no prazo de 30 dias após eliminação da conta. |
| Apostas ativas | Enquanto a aposta estiver ativa. |
| Histórico de apostas | Enquanto a sua conta estiver ativa ou até eliminação manual. |
| Códigos de verificação / reposição | Máximo 15 minutos. |
| Registos de acesso ao servidor | 30 dias. |
| Registos contabilísticos de subscrições pagas | Conforme exigido pela lei fiscal aplicável (geralmente até 10 anos). |
| Tokens de notificação push | Até revogar a permissão ou desinstalar a Aplicação. |

---

## 8. Os seus direitos

Ao abrigo do RGPD, tem direito a: **Acesso**, **Retificação**, **Apagamento** (disponível na Aplicação em **Definições → Conta → Eliminar conta**), **Limitação do tratamento**, **Portabilidade**, **Oposição** e **Retirada do consentimento**.

Para exercer estes direitos, escreva para **dycersofficial@gmail.com** a partir do endereço de e-mail associado à sua conta. Responderemos no prazo de um (1) mês.

---

## 9. Segurança

Aplicamos medidas técnicas e organizativas apropriadas: encriptação **TLS (HTTPS)**, hash **bcrypt** para palavras-passe, tokens **JWT** em armazenamento seguro da plataforma (`expo-secure-store`) e acesso restrito aos sistemas de produção.

---

## 10. Menores

A Aplicação **não se destina a menores**. Não recolhemos conscientemente dados de pessoas com menos de 18 anos. Contacte-nos em **dycersofficial@gmail.com** se acreditar que um menor nos forneceu dados pessoais.

---

## 11. Cookies e tecnologias semelhantes

A Aplicação é uma aplicação móvel nativa e não utiliza cookies web tradicionais. Utiliza armazenamento local (`expo-secure-store`, `AsyncStorage`) para memorizar sessão, idioma e preferências.
